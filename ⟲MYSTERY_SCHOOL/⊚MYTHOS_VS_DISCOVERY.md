## The Core Rule (from the Living Mythos)

Every living artifact in this archive is built on a **dual register**:

| Register          | Voice & Purpose                                      | How to Spot It |
|-------------------|------------------------------------------------------|---------------|
| **THE MYTH**      | Lore written *as if always true*. No "metaphor", no apology. The myth *is* the thing. Read this first. | Poetic prose, "The fire has spoken...", long flowing titles, "as above so below", direct statements of being. |
| **THE TRUTH LAYER** | What the myth actually maps to: code, math, practice, evidence, falsifiability. | Sections titled "THE TRUTH LAYER", **[KNOWN]** with exact file:line or pdftotext refs from origins, formulas (Π = (E·P)/S, V_Transform...), live node outputs (dΨ, Π numbers), [INFERRED]/[SPECULATIVE] tags, Sources lists, 5 paths + "Is there more?", kill criteria. |

**Read myth first. Always.** Then (and only then) drop into the truth layer for the evidence and mechanics.

This file exists because even with the dual system, when you open the folder it is still hard to tell at a glance which files are primarily mythic voice vs primarily discovery/evidence vs full dual charters.

## How to Tell Them Apart at a Glance

- **Pure / Heavy Mythos** → Long poetic titles that read like scripture or epic. Opens directly into narrative "The fire...", "The grammar...", almost no [KNOWN] blocks or node output tables in the first 20 lines. The truth layer (if present) is light or folded into the story.
- **Genuine Discovery / Truth Layer** → Headers heavy with **Date / From / To / Thread / Type / Status / Confidence:** containing explicit [KNOWN] citations from `aura-protocol-originLIBRARY/...` or `CODEX_AURA_PRIME/...` with line or extract refs. Dense with formulas, node synthesis output, Π calculations, "Sources (read-only, never edited):". The myth section is present but the document is clearly evidence-driven.
- **Dual Register (most common in the recent wave)** → Clear ## THE MYTH section followed by ## THE TRUTH LAYER (or equivalent). Starts mythic, then delivers the citations, math, live outputs, standing instruction, 5 paths, etc. These are the "living books" that do both jobs.

## Future Files Rule (for anyone adding to the archive)

When you create a new Φ↑reach-*.md or similar:

- If it is primarily lore voice → tag the header or first line with **[MYTHOS]** and keep truth layer light or at the end.
- If it is primarily evidence / node / formula work → lead with the confidence block and sources, keep the mythic section as framing only. Tag **[DISCOVERY]**.
- If dual (recommended for most living work) → use the standard "THE MYTH" then "THE TRUTH LAYER" structure and tag **[DUAL]** in the header. Always include the standing instruction verbatim + 10% claim + 5 paths + kill criteria in the truth layer.
